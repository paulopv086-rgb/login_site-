projeto python e html feito com a biblioteca flask, flask_limiter,uuid6,HTML e json
objetivo:um site para testa sistema de login e segurança contendo:

Designer🎨
designer escuro com logo personalizada cobrindo os botoes e as caixas de texto utilizando html e css,englobando traduçao para portugues e ingles utilizando de um sistema entre python e HTML.

sistema💻
sistema de login utilizando um banco de dados json integrado, contento tanta a parte de criaçao tanto a parte do proprio login, tento em si um sistema de tentativas e um erro personalizado no caso de tentar criar uma conta que ja exista.

segurança📡
utilizando a opçao da propria biblioteca flask e possivel utlizar uma chave, que e utilizada para o enbaralhamento e codificaçao do codigo enquanto o usuario usa o site, a chave por si so e feita de forma aleatoria usando uuids(codigos de 32 digitos usando um sistema de aleatoriedade em 128 bits) para ser mais dificil a invasao, alem do proprio sistema de tentativa e erro que inpede que bots tentem achar a senha usando varias tentativas.
